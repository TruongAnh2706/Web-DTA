@System Role: Bạn là một chuyên gia Senior Frontend Developer chuyên về giao diện ngụy trang (Stealth UI). Hãy xây dựng trò chơi Bắn Tàu (Battleship) được ngụy trang hoàn toàn dưới dạng một Network Diagnostics Dashboard (Bảng kiểm tra xung đột máy chủ).

@Tech Stack: Next.js, Tailwind CSS, Lucide React.

@Yêu cầu về giao diện (UI):
1. Tổng quan thiết kế (Dashboard Console):
- Background: Màu tối thẫm (Dark Mode sâu như nền Terminal), kết hợp với hiệu ứng Glassmorphism (kính mờ) cho các panel chứa lưới Grid.
- Layout: Chia màn hình thành 2 khu vực chính nằm cạnh nhau (Split View) hoặc dùng Tabs: 
  + Khu vực 1: "Local Cluster Status" (Lưới 10x10 hiển thị máy chủ của người chơi).
  + Khu vực 2: "Remote Target Diagnostics" (Lưới 10x10 để người chơi click Ping/Bắn).
- Tọa độ lưới: Các cột là "Port 1 đến 10", các hàng là dải IP "192.168.1.X" (X từ 1 đến 10).

2. Trạng thái Game & Tương tác (Stealth Mode):
- Đặt máy chủ (Setup Phase): Người chơi kéo thả hoặc click để đặt các cụm máy chủ (Chiếm từ 2 đến 4 ô liên tiếp). Các ô được đặt sẽ có viền sáng mờ màu Neon Blue (#00f3ff).
- Khi Bắn (Ping Phase): Nhấp vào lưới "Remote Target" để gửi lệnh kiểm tra.
  + Nếu Trượt (Miss): Ô hiển thị text nhỏ "200" hoặc icon checkmark nhỏ xíu, màu xanh lá mờ. Log hệ thống ghi: "Node [IP] responded in 14ms".
  + Nếu Trúng (Hit): Ô nháy viền màu Neon Red (#ff003c) và hiển thị "500" hoặc icon X. Log hệ thống báo: "[ERROR] Node [IP] timeout conflict".
- Sử dụng font chữ 'Fira Code' hoặc 'Consolas' cho toàn bộ text để tạo cảm giác đang đọc Terminal.

3. Khung Log Hệ thống (System Logs):
- Phía dưới hai lưới Grid, tạo một khung scrollable dạng Terminal.
- Mỗi lượt đi của cả hai bên đều in ra một dòng lệnh giả lập. Ví dụ: `> EXEC PING 192.168.1.4: [TIME OUT - CRITICAL HIT]` hoặc `> EXEC PING 192.168.1.7: [OK]`.

4. Tính năng "Boss Key":
- Lập trình phím tắt khẩn cấp: Nhấn `Ctrl + Space` hoặc `Esc` sẽ lập tức ẩn giao diện lưới và hiển thị một khối code JSON khổng lồ đang chạy tự động hoặc tài liệu API Docs nhàm chán.

@Yêu cầu Code: 
- Quản lý trạng thái bằng `useState` cho hai lưới (Board trạng thái 0: rỗng, 1: có tàu, 2: bắn trượt, 3: bắn trúng).
- Tách biệt các component: `DiagnosticBoard`, `ConsoleLog`, `NodeCell`.
- Code sạch, tối ưu hiệu năng render để chuẩn bị tích hợp WebSockets/Supabase Realtime cho chế độ Multiplayer.
